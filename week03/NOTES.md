# 3주차 배운 것 (Claude 정리)

## 파이썬
- `while True:` 무한 반복 + `break` 탈출 + `input()` 사용자 입력 대기
- 문자열 비교는 대소문자 구분 (`"/BYE" != "/bye"`) — 실무에선 `.lower()`로 정규화
- `list.append()` — 목록 끝에 추가. history를 루프 **밖**에 선언해야 기억이 유지됨
- 들여쓰기는 깊이가 일관되면 몇 칸이든 허용 (관례는 4칸)
- **에러 난 줄 ≠ 원인 줄** — 한 줄이 벽에 붙으면 블록이 끊겨서 몇 줄 아래에서 IndentationError가 남.
  에러 줄 위쪽을 의심할 것

## 핵심 개념: stateless
- **모델은 매 호출이 첫 만남** — 기억은 모델이 아니라 앱 쪽 코드에 있다
- ChatGPT가 기억하는 원리 = 이전 대화 전체(user/assistant 교대)를 매번 통째로 재전송
- 구현: `history.append(내 말)` → `chat(messages=history)` → `history.append(모델 답)`
- 대가 = **토큰 눈덩이**: 매 턴 과거 전체를 재전송하므로 대화가 길수록 입력 토큰 폭증.
  상용 API면 비용 폭탄, 로컬이면 속도 저하. 해결책(요약, 캐싱)은 나중에

## 스트리밍
- `stream=True` → 응답이 조각(part)으로 옴 → `for part in stream:`으로 도착 즉시 출력
- `print(x, end="", flush=True)` — 줄바꿈 없이, 버퍼 없이 즉시
- 조각을 `answer`에 이어붙여 두는 이유: history에는 완성된 답을 넣어야 다음 턴 기억이 온전함

## 실험 기록
- 기억 없음 버전: "내 이름은 창희야" → 다음 턴 "알 수 없습니다" (+ 혼란의 중국어)
- history 버전: "당신의 이름은 창희라고 말씀하셨어요" — 기억 성공
