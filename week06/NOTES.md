## 새 개념
- `open(경로, "w")` — 쓰기 모드. 지금까지 생략한 게 "r"(읽기)였음.
  **"w"는 기존 파일을 경고 없이 덮어씀** — 셸의 `>` 리다이렉트와 같은 위험
- `f.write(문자열)` — print의 파일 버전
- `문자열.replace(a, b)` — 치환으로 출력 파일명 자동 생성 (.txt → _요약.md)
- 삼중따옴표 안에서는 **들여쓰기도 문자열의 일부** — 코드 정렬용 공백이 출력에 샘

## 프롬프트 사고와 해결 (이번 주 핵심 교훈)
- **"비서" 사건**: system에 "너는 비서다"라고 했더니 담당자 불명 칸에 "비서"를 채움 —
  모델은 빈칸을 비워두지 않고 그럴듯한 걸로 채운다 (구조화 출력판 환각)
- 해결: 정체성 단어 제거 + "담당자가 확인되지 않으면 지어내지 말고 '미정'" 규칙 →
  전부 "미정"으로 정직해짐. **규칙이 없으면 지어내고, 규칙이 있으면 따른다**
- STT 전사는 화자 표시·문장부호가 없어 회의록보다 어렵다 → system에 "발화자 표시 없는
  음성 전사"임을 알려주는 것 자체가 품질을 올림
