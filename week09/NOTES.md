# 9주차 배운 것 (Claude 정리) — 마일스톤 2

## 만든 것: 문서 QA 봇 (ask.py)
질문 → week08 인덱스에서 top-3 검색 → 거리 문지기 → 근거를 프롬프트에 조립 →
"근거만으로 답하라" 생성 → 답변 + 출처 표시 = **완전한 RAG 파이프라인**

## RAG의 헌법 (system 프롬프트 규칙들)
- "제공된 근거에 있는 내용만으로 답한다" — 환각 방지의 핵심
- "근거에 없으면 '찾을 수 없습니다'라고만 답한다" — 모른다고 말할 용기를 명시
- "(근거 N) 출처 표시" — 검증 가능성
- "근거의 규칙을 질문 상황에 적용해 판단하라" — 추론 지시

## 4연발 시험에서 배운 것
- 기본 질문 2개: 정확한 숫자 + 출처 ✅
- **함정 질문(김치찌개)**: 벡터 검색은 항상 뭔가를 반환한다(가장 덜 먼 것) —
  그래서 프롬프트 헌법 + 거리 문지기의 이중 방어가 필요. 거리가 신호였음(정상 0.5~0.6 vs 함정 1.38)
- **추론 질문(입사 두 달 재택?)**: 검색은 만점(0.527)인데 생성이 낙제 →
  **RAG 품질 = 검색 품질 × 모델 추론력.** 프롬프트에 "적용해서 판단" 지시 추가로 해결
- 언어 샘 수집 3개 국어째: 중국어, 영어에 이어 포르투갈어("Então")

## 직접 구현한 개선
- 거리 문지기: `if distances[0] > 1.2: print(...); sys.exit(0)` — 모델 호출 전 차단
  (시간 절약 + 환각 위험 제거). 임계값 1.2는 관찰(0.6대 vs 1.38)에서 도출
- 파이썬 블록은 중괄호가 아니라 들여쓰기 — `{sys.exit(0)}`는 집합 문법이라 틀림
