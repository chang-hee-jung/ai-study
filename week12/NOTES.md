# 12주차 배운 것 (Claude 정리) — 마일스톤 3, 커리큘럼 완주

## 만든 것: 멀티스텝 에이전트 (agent.py)
목표 한 문장 → 상태 확인 → 계획 → 도구 연쇄 실행 → 최종 보고.
**챗봇과 에이전트의 경계선 = `if tool_calls:`를 `while tool_calls:`로** 바꾼 것.

## 3번의 실행이 가르쳐준 것 (이번 주의 진짜 교과서)

### 1차: 상한에 잘린 미완성
- 한 라운드에 이동 1건씩만 해서 MAX_ROUNDS=8 소진, 파일 2개 미처리
- 최종 보고는 "넣겠습니다"라고 말만 함 → **에이전트의 보고 ≠ 실제 상태. 검증(ls) 필수**
- 안전벨트(상한)는 폭주를 막지만 작업도 자를 수 있다 — 트레이드오프

### 2차: 대참사 (가장 값진 실행)
- 중국어 누출이 **도구 인자**를 오염 (dst='문档', '其他') — 말 실수는 애교, 행동 실수는 사고
- shutil.move는 목적지 폴더가 없으면 이동이 아니라 **개명**을 함 → 파일 2개가 중국어 이름으로 둔갑
- 에러를 5번 듣고도 같은 호출만 맹목 재시도 (재관찰 없음) → 이번엔 MAX_ROUNDS가 구원자
  (1차와 정반대 — 안전벨트의 양면을 실전으로 체험)
- **승인 피로**: y를 8연타하다 중국어 인자도 통과시킴 — 사람 게이트는 사람이 읽을 때만 작동
- 긴 에러 맥락에 모델 붕괴 (최종 보고가 토큰 샐러드)

### 수습 사이클 (실전 에이전트 운영의 정석)
1. 복구 (개명 파일 원상복귀)
2. **도구 방어 설계**: move_file에 "목적지 폴더 실존 확인 + 없으면 거절하며 교정 힌트 반환"
   — 사고를 없애는 게 아니라 사고가 나도 피해가 안 나게
3. 프롬프트 규칙 보강: "폴더 이름 한국어 그대로", "에러 시 재시도 말고 list_files로 재관찰"

### 3차: 완주
- 3라운드, 전부 한국어 경로, 에러 0, **자연 종료** (모델 스스로 완료 판단)
- 재실행 시 이전 기억 없이 **관찰로 상태 파악** → 반쯤 된 작업을 이어서 완료
  (stateless가 중단·재시작 내성이 되는 원리)

## 파이썬
- `try / except Exception as e:` — 에러를 죽지 않고 잡아서 값으로 다룸.
  에이전트에선 에러도 모델에게 주는 정보다
- MAX_ROUNDS 상한 패턴, 승인 게이트 재사용

## 사용자의 원래 목표와의 관계
"로컬 LLM을 AgentOS에 붙여 작업 위임, 토큰 비용을 전기세로" —
그 문장의 최소 구현이 이 agent.py다. 이제 도구를 늘리는 만큼 위임 범위가 넓어진다.

## 보너스: 에이전트 고도화 (2026-08-02) — "로컬 모델로 ChatGPT/Claude급 체감 내기"

큰 모델로 바꾸는 건 정답이 아니다(13주차: 지능은 하드웨어로 산다) → 대신 agent.py에 4가지를 쌓았다.

1. **CoT 프롬프트**: 도구 호출 전 3단계 자가 점검(확인된 사실만/인자 일치/에러 반복 여부) 삽입,
   최종 보고 전 재확인 의무화
2. **검증 레이어**: `list_files`로 조회한 폴더를 코드가 기억해두고(`last_folder`), 루프 종료 시
   실제로 남은 파일(`leftover_files`)을 코드가 직접 대조 — 모델 말은 참고만, 판정은 코드가 함
3. **RAG 접목**: week08 인덱스를 `search_rules` 도구로 연결(week11 패턴 재사용) — 파일 정리 +
   규정 안내를 한 에이전트가 겸함
4. **모델 에스컬레이션**: 7B로 시작, (a) 같은 에러 반복 또는 (b) 검증 실패(미완료를 완료로 보고)
   시 14B로 자동 전환

### 실전 테스트에서 드러난 것
- 7B가 파일 2개를 안 옮기고 "다음에 처리하겠다"고 말만 하고 루프 종료 → 검증이 적발 → 14B로 전환
- **14B로 올려도 거짓 보고가 사라지지 않음**: 파일 하나를 안 옮기고 "이미 옮겨져 있다"고 보고.
  그런데 코드 검증(`[검증 결과: 미완료]`)이 이걸 그대로 잡아냄
- 결론: **모델을 키워도 신뢰성 문제는 못 없앤다. 검증을 코드로 하는 게 크기보다 중요한 방어선**
  (이게 "로컬 모델을 GPT/Claude급으로" 질문에 대한 실전 답: 모델 자체의 격차보다,
  에이전트 설계(좁은 역할 + 검증 + 에스컬레이션)로 신뢰성 격차를 메우는 게 더 값이 큼)
