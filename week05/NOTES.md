# 5주차 배운 것 (Claude 정리)

## 함수 정의 (파이썬의 큰 산)
- `def 이름(입력) -> 반환형:` — 나만의 명령어. 몸통은 들여쓰기(콜론 규칙)
- `return` = 부른 쪽에 값을 건넴 (print는 화면에 보여줄 뿐 — 다르다)
- **독스트링은 Tool Use에서 모델용 설명서** — 모델이 이걸 읽고 언제 이 함수를 쓸지 판단.
  프롬프트 설계가 함수 설명서로 재등장
- `tools=[함수이름]` — 괄호 없이! 괄호 붙이면 즉시 실행, 없으면 함수 자체를 소개

## Tool Use 핵심 (체크포인트 답)
- **모델은 함수를 실행하지 않는다. 실행해달라는 요청서만 쓴다** —
  tool_calls에 함수명+인자가 옴, 이때 답변은 비어 있음(결과 기다리는 중)
- 실행 권한은 항상 내 코드에 있다 → 이게 안전의 핵심이자 AgentOS의 본질
- 2왕복: 요청 받기 → 실행 → role="tool"로 결과 회신 → 모델이 최종 답변
- 네 번째 role 등장: user / assistant / system / **tool**

## 파이썬 문법 추가
- `available = {"이름": 함수}` — 이름표→실체 전화번호부. 모델이 준 문자열로 함수를 찾음
- `fn(**dict)` — `**`는 dict를 인자로 펼침: {"drive": "F"} → fn(drive="F")
- `shutil.disk_usage()` — 디스크 용량 (df -h의 파이썬판), `datetime.now()` — 현재 시각
