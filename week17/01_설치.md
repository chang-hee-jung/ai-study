# 17주차 2단계 — 설치와 Ollama 연결

처음부터 끝까지 순서대로.

## 0. 준비물 확인

설치 스크립트가 `git`과 `uv`를 쓴다. 없으면 스크립트가 알아서 받아오지만,
이미 있으면 그만큼 빨라진다.

```powershell
git --version
uv --version
ollama list
```

셋 다 나오면 준비 끝이다. `ollama list`가 비어 있으면 모델부터 받아야 한다.

## 1. PowerShell 창 열기

**Git Bash가 아니라 PowerShell이어야 한다.** 설치 스크립트가 `.ps1`이다.

- 시작 메뉴에서 `PowerShell` 검색 → **Windows PowerShell** 실행
- 관리자 권한은 필요 없다. 설치가 `AppData\Local`에만 쓴다.

**폴더는 아무 데나 상관없다.** 전역 설치라 현재 위치와 무관하게
`C:\Users\<사용자>\AppData\Local\hermes` 로 들어간다.

다만 `F:\ai-study` 안에서는 하지 말 것. 이 저장소는 공개라 찌꺼기가 딸려
들어가면 곤란하다.

## 2. 스크립트 받아서 읽어보기

인터넷 스크립트를 그 자리에서 실행하는 `iex (irm ...)` 한 줄보다,
받아서 한 번 보고 실행하는 편이 낫다. 옵션도 줄 수 있다.

```powershell
irm https://hermes-agent.nousresearch.com/install.ps1 -OutFile $env:TEMP\install-hermes.ps1
notepad $env:TEMP\install-hermes.ps1
```

4천 줄이라 다 읽을 필요는 없다. 맨 위 `param(...)` 블록만 봐도 뭘 하는지 감이 온다.

## 3. 설치 실행

```powershell
& $env:TEMP\install-hermes.ps1 -SkipSetup
```

**`-SkipSetup`이 핵심이다.** 이걸 빼면 마지막에 대화형 마법사가 떠서
Nous Portal 가입(OAuth)을 요구한다. 우리는 Ollama로 갈 거라 가입할 이유가 없다.

나중에 웹검색·이미지생성 같은 내장 도구가 필요해지면 그때 `hermes setup`을
따로 돌리면 된다.

파이썬 환경을 새로 까는 것까지 포함이라 몇 분 걸린다.

## 4. 설치 확인

```powershell
hermes --version
hermes config path
hermes doctor
```

`hermes` 명령이 없다고 나오면 PATH가 아직 안 잡힌 것이다.
**PowerShell 창을 닫았다 새로 열면** 대개 해결된다.

`config path`가 알려주는 위치가 3단계에서 해부할 곳이다.
문서에는 `~/.hermes/`라고 돼 있는데 설치 스크립트는 `LOCALAPPDATA`를 쓴다.
어느 쪽인지는 이 명령으로 확인한다.

## 5. Ollama 연결

`hermes config path`가 알려준 경로의 `config.yaml`을 연다.

```powershell
notepad (hermes config path)
```

거기에 이 내용을 넣는다.

```yaml
providers:
  ollama:
    type: openai-compatible
    base_url: http://localhost:11434/v1
    api_key: ollama

model:
  provider: ollama
  default: gemma4:e4b-it-qat
```

`api_key`는 아무 값이나 넣으면 된다. Ollama는 검사하지 않지만
OpenAI 규격상 필드가 비면 클라이언트가 거부하는 경우가 있어서 채워둔다.

모델을 `gemma4:e4b-it-qat`로 고른 근거는 1단계 측정이다(도구 호출 4/4, 제일 가벼움).
모델 이름은 `ollama list`에 나오는 것과 **글자 하나까지 같아야** 한다.

## 6. 첫 실행

```powershell
hermes chat -q "안녕. 너는 어떤 도구를 쓸 수 있어?"
```

`-q`는 한 번 묻고 끝내는 모드다. 대화를 이어가려면 그냥 `hermes chat`.

## 예상되는 문제

### 컨텍스트 초과

이게 제일 먼저 터질 가능성이 높다.

Ollama의 기본 컨텍스트는 4096 토큰이다. 그런데 Hermes는 도구를 수십 개
들고 있어서, 도구 설명만으로 그 창을 넘길 수 있다. 14주차에 KV 캐시를
다루면서 본 그 창이다.

증상은 답이 이상하게 짧거나, 도구를 아예 못 찾거나, 대화가 앞부분을 잊는 식이다.

해결은 컨텍스트를 늘리는 것이다.

```powershell
$env:OLLAMA_CONTEXT_LENGTH = "16384"
```

이걸 주고 Ollama를 다시 띄운다. VRAM을 더 먹으니 8GB 카드에서는
모델 크기와 함께 저울질해야 한다. 14주차에 배운 그 저울이다.

### 모델을 못 찾음

`ollama list`의 이름과 `config.yaml`의 `default`가 다르면 404가 난다.
1단계에서 `agent.py`가 `qwen3:8b`를 못 찾은 것과 같은 종류의 실패다.

### 도구 호출이 안 됨

모델 문제인지 하네스 문제인지 구분해야 한다.
`week17/tool_check.py`로 그 모델을 다시 재보면 어느 쪽인지 갈린다.
1단계를 먼저 해둔 이유가 이것이다.
