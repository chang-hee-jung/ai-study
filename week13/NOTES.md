# 13주차(보너스) 배운 것 (Claude 정리) — 모델 크기 비교: qwen2.5 7B vs 14B

## 실험 설계
- 같은 가족·같은 세대·크기만 2배 — 변인을 크기 하나로 통제
- 시험 3종: 전부 7B의 전과가 있는 문제 (환각/추론/언어누출)
- compare.py: 같은 질문을 두 모델에, eval_count/eval_duration으로 토큰/초 측정

## 결과
| | 7B | 14B |
|---|---|---|
| 언어 규율 | 3판 중 2판 중국어 붕괴 | 전판 한국어 |
| 지시 준수(세 줄/다섯 문단) | 무시 | 준수 |
| 추론(3개월 규정) | 결론은 맞췄으나 신뢰성 불안 | 정답 + 잔여 1개월 계산 + 다음 행동 안내 |
| 환각 | 있음 | 줄었지만 있음 — "PRP"라는 가짜 약어 발명 |
| 속도 | 49 토큰/초 | 10~12 토큰/초 (4~5배 느림) |

## 핵심 교훈
- **지능은 하드웨어로 산다**: 14B(9GB)가 VRAM(8GB)을 넘쳐 CPU 오프로딩 → 4~5배 감속.
  지능↑ 속도↓ 비용↑ 삼각형이 모델 선택의 본질
- **신뢰성 vs 능력**: 7B도 추론을 "가끔" 해냄 — 능력이 있어도 매번 발휘된다는 보장이
  없는 게 작은 모델의 진짜 문제
- **크기는 환각을 줄이지, 없애지 못한다**: 14B도 PRP 발명 — 검증은 항상 필요
- **용도별 이원화가 정답**: 7B = 도구 호출·분류·짧은 요약(손발) / 14B = 추론·긴 글·문서 QA(참모).
  전환 비용은 문자열 한 줄 ("모델은 카트리지")
