# 2주차 배운 것 (Claude 정리)

## 파이썬
- `open(파일, encoding="utf-8")` + `with ... as f:` — 파일 읽기, utf-8은 한글 깨짐 방지
- 콜론(`:`)으로 끝나는 줄 다음은 들여쓰기 (with, if — 괄호 규칙에 이어 두 번째 들여쓰기 규칙)
- f-string: `f"...{변수}..."` — 문자열에 변수 끼워넣기. 프롬프트 조립의 기본
- `sys.argv[1]` = 실행 명령의 첫 인자. `[0]`은 프로그램 자기 자신
- `if len(sys.argv) < 2:` + `sys.exit(1)` — 인자 검사와 비정상 종료 코드
- 문자열은 한 줄에서 열고 닫는다. 긴 문자열(프롬프트)은 `"""..."""` 삼중따옴표

## 에러 3종 추가
- `IndexError: list index out of range` — 목록에 없는 칸 요청 (인자 안 붙이고 실행)
- `SyntaxError: unterminated string literal` — 문자열 중간에 엔터가 들어가 안 닫힘
- **argv[0] 사건**: 에러를 "없애는" 것 ≠ "고치는" 것. [1]→[0]으로 바꾸니 에러는 사라졌지만
  프로그램이 자기 소스코드를 요약하는 엉뚱한 짓을 조용히 함. 조용히 틀리는 게 시끄럽게 죽는 것보다 위험

## 프롬프트 설계
- **system** = 역할과 규칙(직원 수칙), **user** = 이번 요청(주문). 서비스 개발자는 system을 통제한다
- system에 규칙 명시("한국어로만", "숫자 원문 보존", "미확정을 확정처럼 쓰지 말 것")로
  중국어 섞임·숫자 유실·왜곡("검토 중"→"확정") 문제를 잡았다 — 코드 수정 없이
- user 프롬프트 한 줄 교체로 요약 도구 → 결정사항/할일 추출 도구로 변신 (담당자까지 추론해서 붙임)
- **한계**: 그래도 "决定事项" 중국어가 샘 — 프롬프트는 확률을 높일 뿐 보장이 아니다.
  100% 필요하면 더 큰 모델 or 출력 검증/후처리 (4주차 구조화 출력 예고)
- 모델은 요약하며 뭉개고 부풀리고 왜곡할 수 있다. 완료된 일을 할 일로 넣기도. 검수는 사람 몫
